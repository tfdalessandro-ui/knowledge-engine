# Logbook — production target decision: sensalis-node replaces Hetzner CCX23

**2026-09-12, ~12:55 CEST**

## Decision

Owner decision, 2026-09-12: this engine's production deployment runs on
**sensalis-node** — the same machine used for development throughout the
build. The earlier plan to provision a separate Hetzner CCX23 VPS for
production is **cancelled**, not deferred. No CCX23 will be provisioned;
"deploying" means running the service properly on sensalis-node itself
(proper process management — systemd user unit — not just an interactive
session), not moving it to another host.

Practical consequence flagged by the owner: sensalis-node has 2 shared
vCPU / 16GB RAM, less headroom than the CCX23's 4 dedicated vCPU that was
never provisioned. Dev and prod workloads (ingestion, embedding, crawling,
query-serving, plus future research-to-production loop / GA-swarm tuning /
on-demand discovery work from other projects sharing this node) will
compete for the same cores. Watch for it, don't presolve it — report actual
contention (CPU saturation, memory pressure, slow queries under concurrent
load) if observed, rather than assuming it in advance.
