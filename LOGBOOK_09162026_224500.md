**2026-09-16 (22:45 UTC).** Continues the gradual OSE rename.

## Before changing anything

- **No `.env` exists on the node** (checked the live repo and the 14 Sep backup), and the running
  `ose.service` process sets no `KE_*` variables. This looked like it might be another file lost in the migration, but it isn't:
  `data/auto_tune_state.json`'s deployed tuning (weighted fusion, alpha 0.535, rrf_k 1, fanout 100) exactly matches the
  defaults in `src/config/__init__.py`, and auto-tune's last real run reported "No change detected". So there were no
  existing settings to migrate.
- Outside this repo, only the Sensalis clone (both copies, node and laptop) uses `KE_`, through its own separate config. It stays
  untouched until its own rename step.
- Nothing reads cron marker names programmatically.
